Seismic Stream
REFINING - 2026

The Problem: GeoNet publishes live NZ earthquake data but there is no clean pipeline that ingests, stores and visualises it in real time.

My Approach: I built a fully serverless AWS pipeline: a Lambda function pulls from the GeoNet API every 5 minutes via EventBridge, stores events in DynamoDB and a React dashboard displays live quakes on a NZ map with magnitude filtering and significant event alerts.

What I learned: I put my React skills to test and worked to build a project incorperating AWS. This took a decent amount of time to learn and implement. With it I gained experience with Event-driven architecture, serverless compute, NoSQL data modelling and the reliability tradeoffs that come with real-time pipelines. This is the same pattern that powers IoT systems at scale and I am excited to explore it further in future projects.

CourtVision - NBA Stats API
REFINING - 2026

The Problem: Most NBA stat sites make player comparisons unnecessarily cumbersome with too many page loads, inconsistent data formats and no clean API layer to build on top of.

My Approach: Using ESPNS free REST API, I used Java and Spring Boot that integrates with the API-NBA endpoint to serve live standings, team statistics and head-to-head player comparisons. This was built on my prior learning of Java and I'm working to extend it with Spring AI and OpenAI to provide natural language player comparisons. Chatbots are a great way to make data more accessible to the user and I wanted to learn this to use in future.

Challenges: Player IDs need matching across endpoints and certain stat categories are inconsistently populated depending on the season. Writing custom mapping logic to handle these cases cleanly was the core engineering problem.

TCS34725 RGB Colour Sensor
COMPLETED · 2024

Overview: Programmed an Arduino to interface with the TCS34725 colour sensor over I2C using the Wire.h library. The sensor reads real-time RGB values and outputs them to the Serial Monitor.

Technical challenge: Ambient light introduced significant noise into the readings. Learned to calibrate the sensor by adjusting integration time and leveraging the built-in IR filter to get reliable, repeatable results.
