SeismicStream

A serverless AWS pipeline that ingests, stores and maps live New Zealand earthquake data.

Problem
GeoNet publishes live NZ earthquake data, but there was no clean pipeline that ingests, stores and visualises it in real time.
Approach
A Lambda function pulls from the GeoNet API every five minutes on an EventBridge schedule and stores events in DynamoDB. Each record is keyed on its GeoNet quake ID, so a repeat pull updates the same quake instead of duplicating it. A React dashboard shows live quakes on a map of New Zealand with magnitude filtering and alerts for significant events.
What I learned
This put my React skills to the test alongside AWS, which took real time to learn and implement. I gained experience with event-driven architecture, serverless compute, NoSQL data modelling and the reliability tradeoffs that come with real-time pipelines. It is the same pattern that powers IoT systems at scale and I want to explore it further.

2026Refining

CourtVision

A Java and Spring Boot NBA analytics dashboard with live standings, player and team analytics, a next-game predictor and head-to-head comparisons.

Problem
Most NBA stat sites make player comparisons cumbersome, with too many page loads, inconsistent data formats and no clean API layer to build on.
Approach
A Spring Boot REST proxy (controller, service, ESPN) built on ESPN's free public API, with seven endpoints covering standings, teams, rosters, player stats, game logs and today's scoreboard. On top of the raw data it calculates PER, true shooting percentage and assist to turnover ratio, and a weighted-average model projects each team's next game. The frontend is one vanilla HTML, CSS and JavaScript page served by Spring Boot, with AI-generated insights on why teams win.
Challenge
Some stat categories are populated inconsistently depending on the season, so turning raw numbers into reliable metrics meant writing custom mapping logic to handle the gaps cleanly.

About

Identify a real problem, understand it properly, then work backwards to the right solution.

That is how I approach building software. I am a second-year Computer Science student at AUT, majoring in Software Development with minors in Artificial Intelligence and Digital Services.

I am proud to be Māori, Samoan and Tongan. I whakapapa to Ngāti Māhanga, part of Waikato Tainui, and my Pasifika roots are in Salelologa and Kolomotu'a. I am motivated by the chance to create meaningful tools for Māori and Pasifika communities in tech. Whether that is building better infrastructure or exploring how AI could support us in the future, I want my work to connect to something real.

My long-term goal is solutions architecture: designing systems end to end, consulting with customers and sitting where engineering meets commercial strategy. To get there I am building technical depth through projects and AWS certification, and commercial awareness through real work experience.
