NBA Stats API — CourtVision
In Progress · 2026

The Problem: Most NBA stat sites make player comparisons unnecessarily cumbersome with too many page loads, inconsistent data formats and no clean API layer to build on top of.

My Approach: Built a REST API using Java and Spring Boot that integrates with the API-NBA endpoint to serve live standings, team statistics and head-to-head player comparisons. The backend handles data normalisation, response caching to respect API rate limits and graceful fallback for missing fields across different endpoints.

Challenges: The API-NBA data isn't structured for direct comparison — player IDs need matching across endpoints and certain stat categories are inconsistently populated depending on the season. Writing custom mapping logic to handle these cases cleanly was the core engineering problem.

What's next: A team comparison dashboard and a weighted "GOAT score" feature that lets you define which stats matter most to you.

TCS34725 RGB Colour Sensor
High School · 2022

Overview: Programmed an Arduino to interface with the TCS34725 colour sensor over I2C using the Wire.h library. The sensor reads real-time RGB values and outputs them to the Serial Monitor as objects are presented to it.

Technical challenge: Ambient light introduced significant noise into the readings. I learned to calibrate the sensor establishing a baseline, adjusting integration time and leveraging the built-in IR filter. I was able to get reliable, repeatable results as blue returned roughly R24, G64, B155; green R67, G111, B80; red R145, G42, B38.

What I took from it: A practical understanding of low-level hardware communication, sensor calibration and how software and physical components interact. Fundamentals that still inform how I think about systems.

Arduino (C++) I2C / Wire.h Sensor Calibration Embedded Systems
